# Метод найменших квадратів — інтерактивний підручник

Статичний сайт-підручник для тих, хто вперше знайомиться з методом найменших квадратів (МНК).
Шлях — від суперечливих геодезичних вимірів до лінійної регресії в машинному навчанні.

Кожен розділ побудований за одним шаблоном: **проблема → інтуїція та інтерактив → рішення →
🔍 «Хочете більше подробиць?» → зв'язок з ML → код (Python і JavaScript) → місток до наступного розділу.**

## Запуск

Потрібен Node.js 22.12 або новіший (див. `.nvmrc`; з nvm: `nvm install && nvm use`).

```bash
npm install
npm run dev       # локальний сервер розробки
npm run build     # перевірка типів і збірка в dist/
npm run preview   # перегляд зібраної версії
```

Зібраний `dist/` — звичайні статичні файли з відносними шляхами, їх можна викласти на будь-який хостинг
(GitHub Pages, Netlify тощо).

## Структура

```
index.html                     головна сторінка зі змістом
chapters/NN-*.html             сторінки розділів
src/styles.css                 спільні стилі (світла й темна теми)
src/lib/plot.ts                мінімальний SVG-рушій графіків і перетягування
src/lib/linalg.ts              ранг, прямі, генератор випадкових чисел
src/lib/code.ts                блоки коду з вкладками Python/JS і запуском JS
src/lib/common.ts              KaTeX, вправи
src/chapters/chNN.ts           інтерактиви розділу
src/snippets/chNN/*.{py,js}    фрагменти коду (їх можна запустити окремо)
```

Новий розділ: HTML-сторінка в `chapters/`, скрипт у `src/chapters/`, фрагменти в `src/snippets/`
і рядок у `input` в `vite.config.ts`.
